# ClinicCare — ระบบบริหารคิวนัดหมายคลินิก

## ระบบที่รวมให้แล้ว
- Dashboard สรุปจำนวนผู้ป่วย / นัดหมาย / คิวรอ / เสร็จสิ้น
- ลงทะเบียนผู้ป่วย
- ค้นหาผู้ป่วย
- สร้างนัดหมาย
- เลขคิวอัตโนมัติ
- เรียกคิว / เสร็จสิ้น / ยกเลิก
- ดูคิวตามวันที่
- บันทึกประวัติการรักษา
- อาการและการวินิจฉัย
- BP / Temperature / Weight
- การรักษา / ยา / หมายเหตุ
- ดูประวัติย้อนหลังรายผู้ป่วย
- ข้อมูลเก็บใน data/db.json

## วิธีเปิดใน VS Code

ต้องติดตั้ง Node.js 18 ขึ้นไป

เปิดโฟลเดอร์นี้ใน VS Code แล้วเปิด Terminal:

```bash
npm install
npm start
```

จากนั้นเปิด:

http://localhost:3000

## สำคัญ
โปรเจกต์นี้จัดทำเป็นต้นแบบสำหรับงานเรียน/โปรเจกต์ ไม่ควรนำข้อมูลผู้ป่วยจริงมาใส่จนกว่าจะเพิ่มระบบ Login, สิทธิ์ผู้ใช้, การเข้ารหัส, HTTPS, Audit Log และฐานข้อมูลที่เหมาะสมกับการใช้งานจริง
